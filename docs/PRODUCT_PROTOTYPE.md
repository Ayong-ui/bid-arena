# 产品原型

> 本文件只描述**页面、组件与交互**。业务规则见原文，HTTP 接口见 [`openapi.yaml`](openapi.yaml)，事件与 `seq` 见 [`REALTIME_AND_COMMAND_FLOW.md`](REALTIME_AND_COMMAND_FLOW.md)。
> 原型不定义任何业务判定，页面不得成为事实来源。

## 1. 页面地图

```text
/login
  └─ 登录表单

/auctions
  ├─ 拍卖卡片列表（状态、当前价、倒计时、参与人数）
  └─ /auctions/:id
       ├─ 实时状态区
       ├─ 出价区
       ├─ 最近出价表
       ├─ 参与者 / 连接状态
       └─ 结果与资金摘要

/admin/auctions
  ├─ 创建拍卖
  ├─ 开始 / 取消
  └─ 创建 Agent Token（一次性明文展示）

/wallet
  └─ 总余额、冻结余额、可用余额、流水
```

## 2. 全局交互约定（前端立场）

前端是"薄"的，主动放弃业务判定权：

- 倒计时只用服务端 `serverTime` 校准，**不**用本地时钟推断可否出价。
- 出价按钮在请求期间禁用，避免重复提交；网络超时后用**同一个** `requestId` 重试。
- 出价请求同时带请求头幂等键与请求体 `requestId`。
- 保存 `lastSeq`；发现缺口或重连时暂停合并并拉取快照。
- 连接断开显示"重连中"并禁用"假实时"视觉。
- 钱包数字来自服务端快照，**不做本地累加推导**。
- 错误提示按错误码分支，不依赖后端文案。

## 3. 拍卖列表页

- 顶部：当前用户、钱包可用余额、退出。
- 主区：按状态分组的拍卖卡片。
- 卡片字段：标题、状态徽标、当前价、起拍价、截止倒计时、延长次数、参与人数、进入详情。
- 倒计时仅用于展示，服务端状态决定能否出价。

## 4. 拍卖详情页

- **状态头部**：标题、状态、服务端校准倒计时、当前价、匿名领先者、延长次数/上限。
- **出价面板**：金额输入、最低允许金额提示、提交按钮、最近一次请求状态、拒绝原因。
- **出价表**：服务端序号、时间、金额、匿名标识、结果；不泄露他人钱包。
- **连接提示**：已连接 / 重连中 / 已通过快照同步。
- **结束面板**：赢家、成交价、结算原因、本人是否获胜、扣款或释放摘要。

## 5. 管理页

- 创建表单：名称、描述、起拍价、最小加价、持续秒数。
- 操作按钮按状态可用性显示；结算态全部禁用。
- Agent Token 表单：Agent 用户、拍卖范围、权限、过期时间、频率限制。
- 创建成功后高亮显示**一次性** Token，提供复制按钮与"已保存则不可再次查看"提示。

## 6. 钱包页

- 展示总余额、冻结余额、可用余额。
- 流水按时间倒序：类型（冻结 / 释放 / 扣款）、金额、方向、关联拍卖、关联 `requestId`、时间。
- 数字全部来自服务端快照。

## 7. 登录页

- 邮箱与密码表单。
- 登录成功后保存 Token（不写入日志），跳转拍卖列表。
- 提供演示账号入口提示，便于评审快速体验。
